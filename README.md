# Ceylon Tea E-Commerce Website – Manual QA Testing

## Project Overview

This project focuses on the manual quality assurance testing of a Ceylon Tea E-Commerce Website. The purpose of the project is to verify the functionality, usability, input validation, navigation, shopping cart, checkout, and administrative features of the web application.

The project demonstrates practical knowledge of software testing and QA documentation through test case preparation, test execution, defect reporting, and test result analysis.

## Testing Objectives

* Verify that the main system functions work as expected.
* Identify and document software defects.
* Validate user inputs and error handling.
* Test the shopping cart and checkout functionality.
* Verify website navigation and usability.
* Maintain professional QA documentation.

## Testing Scope

The following modules were tested:

* User Registration
* User Login and Logout
* Product Search
* Product Details
* Shopping Cart
* Checkout
* Input Validation
* Website Navigation
* Admin Login
* Product Management

## Project Deliverables

### Test Plan

Contains the testing objectives, scope, testing approach, environment, risks, and deliverables.

### Test Cases

Contains detailed test scenarios, test steps, test data, expected results, actual results, and test status.

### Bug Reports

Contains documented defects with reproduction steps, expected and actual results, severity, priority, and status.

### Test Execution

Contains the results of executed test cases and links each failed test to the relevant defect ID.

### Test Summary

Provides an overall summary of the testing activities, test results, identified defects, and recommendations.

### Screenshots

Contains testing evidence and screenshots captured during the testing process.

## Testing Process

The testing process followed these main steps:

1. Review the application features.
2. Prepare the test plan.
3. Create test cases.
4. Execute the test cases.
5. Record actual results.
6. Identify and document defects.
7. Capture supporting screenshots.
8. Prepare the test execution report.
9. Prepare the final test summary.

## Conclusion

This project demonstrates a structured manual QA testing process for an e-commerce web application. It provides practical evidence of test case design, test execution, defect reporting, and QA documentation.

The project was created as part of a personal QA portfolio to demonstrate practical software testing skills and understanding of the software quality assurance process.
